# Treatment image prompt set

The 19 treatment images in `public/treatments/` were created with OpenAI's built-in image generation mode. The shared direction was: premium modern dental-clinic imagery, natural teal-and-white palette, clinically plausible anatomy and instruments, horizontal editorial composition with a safe 16:9 crop, no text, no logo, no watermark, and no graphic or gory detail.

Photorealistic subjects were used for patient-facing treatments: Hollywood smile, veneers, whitening, bonding, smile makeover, full-mouth restoration, gum treatment, laser gum treatment, bruxism, clear aligners, orthodontics and preventive dentistry.

Clean scientific-educational subjects were used where anatomy or a device communicates the treatment more accurately: implants, All-on-4, crowns, zirconia crowns, composite fillings, root-canal treatment and wisdom-tooth removal.

Each asset has a descriptive, stable URL matching its treatment slug. The production WebP files retain a high-resolution 1672 px width while being compressed for fast delivery.
